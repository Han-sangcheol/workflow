# build.bat 파일 설명서

## 개요
`build.bat`는 Workflow AI Analysis System을 실행 파일(.exe)로 빌드하기 위한 Windows 배치 스크립트입니다.

---

## 줄별 상세 설명

### 초기 설정 (1~3줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 1 | `@echo off` | 명령어 실행 시 명령어 자체가 화면에 출력되지 않도록 합니다. `@`는 이 명령어 자체도 숨깁니다. |
| 2 | `chcp 65001 >nul` | 콘솔의 코드 페이지를 UTF-8(65001)로 변경합니다. `>nul`은 출력 메시지를 숨깁니다. 한글 등 유니코드 문자를 올바르게 표시하기 위함입니다. |
| 3 | `setlocal enabledelayedexpansion` | 지연 환경 변수 확장을 활성화합니다. `!변수!` 문법으로 루프나 조건문 내에서 변수 값을 실시간으로 읽을 수 있게 합니다. |

---

### 헤더 출력 (5~8줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 5 | `echo ====...====` | 구분선을 출력합니다. |
| 6 | `echo   Workflow AI Analysis...` | 프로그램 제목을 출력합니다. |
| 7 | `echo ====...====` | 구분선을 출력합니다. |
| 8 | `echo.` | 빈 줄을 출력합니다. |

---

### 작업 디렉토리 설정 (10~11줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 10 | `REM Change to script directory` | 주석입니다. `REM`은 배치 파일에서 주석을 나타냅니다. |
| 11 | `cd /d "%~dp0"` | 스크립트가 위치한 디렉토리로 이동합니다. `/d`는 드라이브도 함께 변경합니다. `%~dp0`은 현재 배치 파일이 있는 드라이브와 경로를 나타냅니다. |

---

### 가상환경 Python 경로 설정 (13~14줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 13 | `REM Set virtual environment...` | 주석입니다. |
| 14 | `set "VENV_PYTHON=%~dp0.venv\Scripts\python.exe"` | `VENV_PYTHON` 환경 변수에 가상환경의 Python 실행 파일 경로를 설정합니다. |

---

### 가상환경 존재 확인 (16~22줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 16 | `REM Check virtual environment` | 주석입니다. |
| 17 | `if not exist "%VENV_PYTHON%" (` | 가상환경의 Python 실행 파일이 존재하지 않으면 아래 블록을 실행합니다. |
| 18 | `echo [ERROR] Virtual environment...` | 에러 메시지를 출력합니다. |
| 19 | `echo [!] Please create...` | 가상환경을 먼저 생성하라는 안내 메시지를 출력합니다. |
| 20 | `pause` | 사용자가 키를 누를 때까지 대기합니다. |
| 21 | `exit /b 1` | 에러 코드 1과 함께 배치 파일을 종료합니다. `/b`는 현재 배치 파일만 종료합니다. |
| 22 | `)` | if 블록의 끝입니다. |

---

### 진행 상황 표시 (24줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 24 | `echo [1/4] Using virtual...` | 1단계: 사용 중인 가상환경 Python 경로를 표시합니다. |

---

### pip 확인 및 설치 (26~39줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 27 | `echo.` | 빈 줄을 출력합니다. |
| 28 | `echo [2/4] Checking build tools...` | 2단계: 빌드 도구 확인 중임을 표시합니다. |
| 29 | `"%VENV_PYTHON%" -m pip --version >nul 2>&1` | pip 버전을 확인합니다. `>nul 2>&1`은 표준 출력과 에러 출력을 모두 숨깁니다. |
| 30 | `if errorlevel 1 (` | 이전 명령어가 실패하면(에러 코드 1 이상) 아래 블록을 실행합니다. |
| 31 | `echo [!] pip not found...` | pip가 없다는 메시지를 출력합니다. |
| 32 | `"%VENV_PYTHON%" -m ensurepip --upgrade` | Python 내장 모듈로 pip를 설치/업그레이드합니다. |
| 33-37 | `if errorlevel 1 (...)` | pip 설치 실패 시 에러 메시지 출력 후 종료합니다. |
| 38 | `echo [DONE] pip installed...` | pip 설치 성공 메시지를 출력합니다. |
| 39 | `)` | if 블록의 끝입니다. |

---

### PyInstaller 확인 및 설치 (41~53줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 42 | `"%VENV_PYTHON%" -m PyInstaller --version >nul 2>&1` | PyInstaller가 설치되어 있는지 확인합니다. |
| 43 | `if errorlevel 1 (` | PyInstaller가 없으면 아래 블록을 실행합니다. |
| 44-45 | `echo [!] PyInstaller...` | PyInstaller가 없다는 메시지와 설치 시작 메시지를 출력합니다. |
| 46 | `"%VENV_PYTHON%" -m pip install pyinstaller` | pip를 통해 PyInstaller를 설치합니다. |
| 47-51 | `if errorlevel 1 (...)` | 설치 실패 시 에러 메시지 출력 후 종료합니다. |
| 52 | `echo [DONE] PyInstaller installed...` | 설치 성공 메시지를 출력합니다. |
| 53 | `)` | if 블록의 끝입니다. |

---

### 아이콘 생성 (55~65줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 57 | `echo [2.5/4] Creating icon...` | 2.5단계: 아이콘 생성 중임을 표시합니다. |
| 58 | `if not exist "resources\icon.ico" (` | 아이콘 파일이 없으면 아래 블록을 실행합니다. |
| 59 | `"%VENV_PYTHON%" -c "import PIL" >nul 2>&1` | Pillow(이미지 처리 라이브러리)가 설치되어 있는지 확인합니다. |
| 60-63 | `if errorlevel 1 (...)` | Pillow가 없으면 설치합니다. |
| 64 | `"%VENV_PYTHON%" build\create_icon.py` | 아이콘 생성 스크립트를 실행합니다. |
| 65 | `)` | if 블록의 끝입니다. |

---

### 빌드 실행 (67~78줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 69 | `echo [3/4] Starting build...` | 3단계: 빌드 시작을 표시합니다. |
| 71 | `"%VENV_PYTHON%" build\build.py --clean %*` | 메인 빌드 스크립트를 실행합니다. `--clean`은 이전 빌드 결과물을 정리합니다. `%*`는 배치 파일에 전달된 모든 인자를 그대로 전달합니다. |
| 73-78 | `if errorlevel 1 (...)` | 빌드 실패 시 에러 메시지 출력 후 종료합니다. |

---

### 완료 메시지 및 결과 안내 (80~88줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 81 | `echo [4/4] Build complete!` | 4단계: 빌드 완료를 표시합니다. |
| 84 | `echo   Output location:` | 출력 파일 위치 안내 시작입니다. |
| 85 | `echo   - Executable: dist\...` | 실행 파일 경로를 안내합니다. |
| 86 | `echo   - Installer: dist\installer\...` | 설치 프로그램 경로를 안내합니다. |

---

### 출력 폴더 열기 옵션 (90~98줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 91 | `set /p OPEN_FOLDER="Open output folder? (Y/N): "` | 사용자에게 출력 폴더를 열지 물어봅니다. `/p`는 사용자 입력을 받습니다. |
| 92 | `if /i "!OPEN_FOLDER!"=="Y" (` | 사용자가 Y를 입력하면 아래 블록을 실행합니다. `/i`는 대소문자를 구분하지 않습니다. `!변수!`는 지연 확장 변수입니다. |
| 93-94 | `if exist "dist\installer" (...` | installer 폴더가 있으면 해당 폴더를 Windows 탐색기로 엽니다. |
| 95-97 | `else if exist "dist" (...` | 없으면 dist 폴더를 엽니다. |
| 98 | `)` | if 블록의 끝입니다. |

---

### 종료 (100줄)

| 줄 | 코드 | 설명 |
|---|------|------|
| 100 | `endlocal` | `setlocal`으로 시작된 환경 변수 범위를 종료합니다. 스크립트에서 설정한 환경 변수들이 외부에 영향을 미치지 않도록 합니다. |

## 빌드 프로세스 흐름도

```
┌─────────────────────────────────────┐
│ 1. 초기 설정                         │
│    - UTF-8 인코딩 설정              │
│    - 스크립트 디렉토리로 이동        │
└───────────────┬─────────────────────┘
                ▼
┌─────────────────────────────────────┐
│ 2. 가상환경 확인                     │
│    - .venv\Scripts\python.exe 확인  │
│    - 없으면 에러 → 종료             │
└───────────────┬─────────────────────┘
                ▼
┌─────────────────────────────────────┐
│ 3. 빌드 도구 확인/설치               │
│    - pip 확인 (없으면 설치)         │
│    - PyInstaller 확인 (없으면 설치) │
└───────────────┬─────────────────────┘
                ▼
┌─────────────────────────────────────┐
│ 4. 아이콘 생성                       │
│    - icon.ico 없으면 생성           │
│    - Pillow 필요시 설치             │
└───────────────┬─────────────────────┘
                ▼
┌─────────────────────────────────────┐
│ 5. 메인 빌드 실행                    │
│    - build\build.py --clean 실행   │
└───────────────┬─────────────────────┘
                ▼
┌─────────────────────────────────────┐
│ 6. 완료                              │
│    - 결과물 위치 안내               │
│    - 폴더 열기 옵션 제공            │
└─────────────────────────────────────┘
```

## 주요 환경 변수

| 변수명 | 설명 |
|--------|------|
| `VENV_PYTHON` | 가상환경의 Python 실행 파일 경로 |
| `OPEN_FOLDER` | 사용자가 입력한 폴더 열기 여부 (Y/N) |

---

## 출력 파일 위치

- **실행 파일**: `dist\WorkflowAnalyzer\WorkflowAnalyzer.exe`
- **설치 프로그램**: `dist\installer\WorkflowAnalyzer_Setup_*.exe`

---

## 사용 방법

```batch
# 기본 빌드
build.bat

# 추가 옵션과 함께 빌드 (옵션은 build.py로 전달됨)
build.bat --option1 --option2
```
